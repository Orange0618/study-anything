# Domain adaptation

Keep the progress-review contract stable while adapting practice and evidence to the field.

## Software and data

- Practice: runnable programs, debugging tasks, experiments, integration projects.
- Evidence: source code, tests, structured results, plots, benchmarks, README files.
- Reproducibility: dependency manifest, versions, seed, commands, sample inputs.

## Hardware and embedded systems

- Practice: wiring, firmware, measurement, deployment, fault diagnosis.
- Evidence: source, schematics, bill of materials, serial logs, measurements, photos, power or latency data.
- Reproducibility: board revision, toolchain, firmware version, wiring, instruments, safety limits.

## Mathematics and quantitative subjects

- Practice: derivation, proof, computation, counterexample, application problems.
- Evidence: worked solutions, corrected errors, oral explanations, timed sets, verification scripts.
- Reproducibility: assumptions, notation, source problem, complete intermediate reasoning.

## Product, business, and design

- Practice: case analysis, requirements, prototype, metric design, trade-off decisions, user research.
- Evidence: PRD, prototype, decision log, evaluation rubric, interview notes, experiment plan.
- Reproducibility: scenario, constraints, input data, success metric, decision rationale.

## Languages and communication

- Practice: comprehension, production, correction, spaced retrieval, authentic scenarios.
- Evidence: recordings, corrected writing, vocabulary-in-context, rubric scores, before/after samples.
- Reproducibility: prompt, target level, correction criteria, repeated assessment conditions.

## Research and academic fields

- Practice: literature search, claim comparison, method replication, critique, synthesis.
- Evidence: source ledger, annotated bibliography, replication notebook, claim-evidence table, draft review.
- Reproducibility: search query, databases, dates, inclusion criteria, versions, data and method details.

## Structure selection

Do not create empty directories merely to match a template. Preserve these logical roles even if names change:

- explanation or notes;
- practice;
- validation;
- evidence;
- review.
